# Agentes de IA y automatización con Codex CLI y Claude Code

Temario base compartido para trabajar con cualquiera de las dos herramientas.

- **Duración:** 10 horas por persona.
- **Distribución:** 5 sesiones de 2 horas.
- **Modalidad:** teórico-práctica.
- **Tecnologías:** Codex CLI o Claude Code, terminal, Visual Studio Code, Git, Python y MCP.

## Objetivo general

Utilizar Codex CLI o Claude Code como agente de trabajo desde la terminal para automatizar procesos con datos: desde el manejo de la línea de comandos, Visual Studio Code, Git y Python, hasta la conexión con herramientas mediante MCP, la creación de agentes y la construcción de una oficina virtual con IA.

Al finalizar, los participantes podrán diseñar, ejecutar, validar y documentar un proceso empresarial automatizado con agentes de datos, análisis y reporte.

## Sesión 1. Línea de comandos y Visual Studio Code

**Duración: 2 horas.**

### Línea de comandos — 1 hora

- Qué es la terminal y por qué los agentes trabajan desde ella.
- Directorios, rutas absolutas y relativas.
- Navegación, creación y organización de carpetas y archivos.
- Comandos esenciales: listar, copiar, mover, renombrar y eliminar.
- Lectura e interpretación de errores en la terminal.

### Visual Studio Code — 1 hora

- Apertura de proyectos y organización de archivos.
- Terminal integrada y ejecución de comandos dentro del editor.
- Extensiones para trabajar con la herramienta elegida.
- Instalación, inicio de sesión y primeras instrucciones con Codex CLI o Claude Code.

**Resultado:** navegarán con seguridad en la terminal, trabajarán un proyecto en Visual Studio Code y ejecutarán sus primeras instrucciones con el agente.

## Sesión 2. Git, control de versiones y Python para datos

**Duración: 2 horas.**

### Git y control de versiones — 1 hora

- Concepto de repositorio, inicialización y clonación.
- Commits, mensajes e historial de cambios.
- Revisión de los cambios propuestos por la IA antes de aceptarlos.
- Recuperación de versiones anteriores y corrección de errores.

### Python para datos — 1 hora

- Lectura de archivos de Excel con Python.
- Limpieza de datos y aplicación de reglas de validación.
- Cruces entre tablas y cálculos.
- Exportación de resultados.
- Generación, revisión y ejecución de scripts con el agente.

**Resultado:** controlarán las versiones de su trabajo y automatizarán el procesamiento de un archivo de Excel con un script de Python generado y revisado con el agente.

## Sesión 3. MCP y creación de agentes

**Duración: 2 horas.**

### MCP (Model Context Protocol) — 1 hora

- Qué es MCP y para qué sirve.
- Conexión de agentes con herramientas, archivos y servicios.
- Configuración de servidores MCP en la herramienta elegida.
- Permisos, alcance y seguridad de las conexiones.

### Creación de agentes — 1 hora

- Definición del objetivo de cada agente y uso de subagentes.
- Asignación de responsabilidades y límites.
- Contexto e instrucciones reutilizables: `AGENTS.md` en Codex y `CLAUDE.md` en Claude Code.
- Uso de skills para tareas reutilizables.
- Coordinación y entrega de trabajo entre agentes.

**Resultado:** conectarán el agente con herramientas externas mediante MCP y diseñarán agentes con objetivos, responsabilidades y contexto claros.

## Sesión 4. Oficina virtual con IA

**Duración: 2 horas.**

- Selección y diseño de un proceso empresarial.
- Agente de datos: obtención y preparación de la información.
- Agente de análisis: cálculos, cruces e indicadores.
- Agente de reporte: redacción y presentación de resultados.
- Flujo de trabajo y coordinación entre los agentes.
- Ejecución del proceso completo con la herramienta elegida.
- Supervisión humana y puntos de control.

**Resultado:** tendrán una oficina virtual en la que agentes de datos, análisis y reporte resuelven un proceso empresarial de principio a fin.

## Sesión 5. Implementación, validación y reporte final

**Duración: 2 horas.**

### Implementación y validación — 1 hora

- Pruebas del proceso y revisión de resultados.
- Identificación y corrección de errores.
- Prueba de escenarios distintos.
- Control de versiones de la solución.
- Ejecución final del proceso.

### Reporte final — 1 hora

- Definición y cálculo de indicadores.
- Validación de la información reportada.
- Presentación de resultados.
- Documentación del proceso para replicarlo y mantenerlo.

**Resultado:** contarán con un proceso validado, versionado y documentado, y presentarán un reporte final con sus indicadores.

## Proyecto práctico

Cada participante construirá una oficina virtual con IA capaz de:

- Recibir un archivo de Excel con información de un proceso empresarial.
- Limpiar, validar y cruzar la información con Python.
- Conectarse con herramientas y archivos mediante MCP.
- Distribuir el trabajo entre agentes de datos, análisis y reporte.
- Ejecutarse desde la terminal con Codex CLI o Claude Code.
- Mantenerse en un repositorio de Git con su historial de cambios.
- Validarse con pruebas y distintos escenarios.
- Generar un reporte final con indicadores.
- Contar con documentación para replicar su funcionamiento.

## Alcance del programa

- Trabajar con seguridad en la línea de comandos.
- Organizar proyectos y usar la terminal integrada de Visual Studio Code.
- Instalar, configurar y dar instrucciones a la herramienta elegida.
- Controlar versiones con Git y recuperar cambios.
- Procesar, limpiar y cruzar datos de Excel con Python.
- Conectar agentes con herramientas, archivos y servicios mediante MCP.
- Diseñar agentes con objetivos, responsabilidades y contexto.
- Construir una oficina virtual que automatice un proceso empresarial.
- Probar, validar e implementar la solución.
- Presentar y documentar resultados con indicadores.

## Uso del temario base

Los temas, la duración, los resultados y el proyecto práctico son los mismos para ambos cursos. Las demostraciones y los ejercicios se realizan con Codex CLI o Claude Code, según la herramienta elegida para la capacitación.
